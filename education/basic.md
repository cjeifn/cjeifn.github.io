# 기본 과정(15시간)

{% include section.html %}

![]({{ '/images/basic-course.jpg' | relative_url }})

{% include section.html %}

기초 수리력 지도를 위한 기본 이론과 원리를 익히는 과정입니다. 기초수리력과 수학학습곤란의 의미, 학습지원대상학생의 진단, 학생의 오류를 해석하고 지도하는 방법을 다룹니다. 교사는 이를 통해 학생의 어려움을 이해하고 기초수리력 지도를 설계하는 데 필요한 기본적인 역량을 갖출 수 있습니다.

{% include section.html %}

* **1회기(3시간) :** 기초 수리력 개념 및 기초 수리력 진단 도구의 이해
* **2회기(3시간) :** 수학학습곤란 학생의 이해
* **3회기(3시간) :** 기초수리력 지도 사례 탐구
* **4회기(3시간) :** 오류 유형별 지도 방안(자연수의 연산, 분수 개념)
* **5회기(3시간) :** 오류 유형별 지도 방안(분수와 소수 연산)
